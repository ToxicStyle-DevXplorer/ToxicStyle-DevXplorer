### About

Software and systems engineer focused on low-level programming, custom embedded hardware, and full-stack web applications. Interested in clean architecture, deterministic performance, and minimalist developer tooling.

- **Systems & Application Development:** Writing efficient native code in `C++`, automation and machine learning pipelines in `Python`, and responsive web interfaces with `JavaScript` and `Tailwind CSS`.
- **Hardware & Firmware:** Designing and building wireless ergonomic split keyboards (`Corne` / `nRF52840` / `ZMK`) and interactive microcontroller prototypes on `ESP32-S3`.
- **Current Focus:** Developing **SkillOrbit** (a peer-to-peer skill-sharing platform) and training autonomous reinforcement learning agents in **Godot Engine 4**.
